# Oolung
## В этом репозитории собраны все модели, которые я, вместе со своей командой, разработал в ходе обучения на треке ML специализаций Яндекса в 2023 году.
## Постановка задачи:
### Дан датасет, состоящий из рентгеновских снимков лёгких. Также, имеется датасет, содержащий в себе чёрно-белые маски к изображениям тренировочной выборки. Необходимо обучить модель, которая будет предсказывать наличие у пациента пневмонии какого-либо типа, или конкретно ковидной пневмонии (или её отсутствие соответственно)
### Файл Unet_realisation.ipynb содержит реализацию модели, генерирующей маску легких по исходному xray снимку
### Файл YML2023N-6_final.ipynb содержит реализацию финальной самой результативной модели и её логи
### Файл solution_with_Unet_masks.ipynb содержит реализацию ансамбля моделей с использованием масок
### Файл solution_without_masks.ipynb содержит однк из реализаций без использования масок соответственно.
